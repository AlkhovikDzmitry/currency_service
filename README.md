Сервис для обмена валют с автоматической загрузкой актуальных курсов с API Национального Банка Республики Беларусь (НБРБ).

Стек технологий
- Python 3.11
- FastAPI
- PostgreSQL 15
- SQLAlchemy 2.0
- APScheduler
- Docker / Docker Compose

Как запустить

Для запуска потребуется установленный Docker Desktop (или Docker Engine + Docker Compose).

1. Клонируйте репозиторий и перейдите в папку с проектом:
   ```bash
   git clone https://github.com/AlkhovikDzmitry/currency_service
   cd currency_service

2. В тиериминале запустите сборку и старт контейнеров одной командой:
    docker compose up --build

3. Дождитесь, пока в логах появится сообщение "Курсы обновлены" и "Application startup complete".

4. Документация API (Swagger)

После успешного запуска интерактивная документация доступна по адресу:
http://localhost:8000/docs

Там вы можете протестировать все эндпоинты прямо из браузера.

Реализованный функционал

Сбор курсов валют: При старте сервиса и далее раз в 24 часа фоновый планировщик (APScheduler) обращается к API НБРБ и сохраняет курсы в базу данных.

Двухэтапный обмен:

POST /exchange/preview — принимает сумму и валюты, рассчитывает сумму к получению по актуальному курсу, создает сделку в статусе pending и возвращает её ID.

POST /exchange/confirm — принимает ID сделки и действие (confirm или reject). Меняет статус сделки на completed или rejected.

Отчет по сделкам: GET /exchange/report — возвращает агрегированную информацию (сумма прихода, сумма расхода, количество сделок) за указанный интервал времени с опциональным фильтром по валюте.

Незавершенные сделки: GET /exchange/pending — возвращает список сделок в статусе pending.

5. База данных

Сервис использует PostgreSQL. При первом запуске автоматически создаются необходимые таблицы (currencies, exchange_rates, transactions). Данные сохраняются в Docker-волуме pgdata, поэтому не пропадают при перезапуске контейнеров.

Как остановить

Чтобы остановить контейнеры, нажмите Ctrl+C в терминале или выполните:
    docker compose down
